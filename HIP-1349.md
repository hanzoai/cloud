# HIP-1349: eBPF Runtime Enforcement for Visor

## Abstract
Integrate Tetragon-based eBPF enforcement to provide kernel-level security for agent sandboxes, preventing escapes via syscall filtering.

## Specification
- **Component:** `visor` / `runtime`
- **Mechanism:** `TracingPolicy` (eBPF)
- **Enforcement Points:**
    - `sys_execve`: Block any binary execution not explicitly whitelisted for the agent.
    - `tcp_connect` / `udp_sendmsg`: Block network egress unless the agent has the `NET_RAW` capability.
    - `sys_write`: Audit sensitive file modifications.

## Security Considerations
Tetragon runs in the kernel. A misconfigured policy could kill the main `cloud` process. Policies must be scoped strictly to the child PIDs of the agent runtime.
